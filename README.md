# tournament_mode - AI Slop Edition (Use at your own risk)

Tournament mode for CTF. It injects tournament rosters, spectators and match flow into the builtin CTF modes (classes, classic, nade_fight, and other modes using the capturetheflag API) instead of shipping its own mode. Managers pick the mode and map via /teamform.

This mod should only be used on server dedicated to running tournament matches. It's possible for players to end up without interact privs if you disable the mod.
